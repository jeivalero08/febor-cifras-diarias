# febor-cifras-diarias
Dashboard financiero interactivo de FEBOR Entidad Cooperativa. Seguimiento diario de depósitos, evolución histórica de saldos por producto (Ahorro Voluntario, CDAT, Daes, Aportes, Ahorro Contractual, Bolsillo Rentable) e indicadores clave.
